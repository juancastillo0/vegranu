### Recipes

#### Auxiliary Ingredients & Preparations

Foods and auxiliary ingredients that are part of a whole meal. High level instructions that allow for flexibility along with
specific variants with particular measures.

- Change serving sizes
- Change measurements: weight vs volume, kilograms vs pounds
- Nutritional tables
- Swaps and allergies, globally configured for the user
- Favorites and add to lists
- Tags for foods: Sweet, Savory, Sandwich, Soup, Snack, Countries
- Create or edit a new recipe or meal and share
- Import recipe from url

#### Nutrients, Food Search & FoodDB

- Search for foods and ingredients with multiple filters and orders
  - micronutrients
  - macronutrients
  - healthfulness
  - belongs to a dietary pattern
- Swaps or similar foods
- Create or edit a new food or ingredient and share
- Use url for filtering so that the sharing could be performed

- Search ingredients/preparations by nutrient per serving/gram/volume
- Search foods with nutritional tables and suggest swaps or alternatives
- Pre-made lists/filters and columns
  - Order by nutrient/antioxidant-dense
  - Healthfulness column
  - Belongs to a dietary pattern
  - Resource Use for foods

#### Tool for validating scientific evidence:

- Search the knowledge graph of the input
- For each item, retrieve relevant information (for and against) from trusted sources
  - If there is no data, return unknown
- Validate whether the hypothesis is consistent with the evidence
  - List issues and caveats for the hypothesis. For example sex, age, region specific considerations
- Use the hierarchy, quality and amount of evidence, along with the alignment with research to determine a consensus score
